# TimberlineRecompiled
Recomp of the Xbox 360 version of Open Season (WIP/Experimental)

Disclaimer that this requires Rexglue if you want to codegen and compile, there is a release available. But as is the case for any recomp, you do need a legally obtained copy of the game. And in this case, the NTSC version.

Game assets go in the "openseason" folder.

Why did I do a recomp for the game when an official PC version exists?

Mainly because that version is more based on the sixth gen version with it being on par with the Original Xbox version.

As such the game on PC never got the enhancements of the Xbox 360 version including widescreen support.

Also important to note this as WIP/Experimental, as such it doesn't include any patches or enhancements, stuff like those can be made using the ingame settings of Rexglue.

-----
do know that because of issues with Rexglue and its GPU plugin (which is based off Xenia, and a somewhat older version of it), it seems to have a few visual issues compared to the original game and playing on Xenia. Please be aware of this issue, right now there's no native renderer or anything else like that.
